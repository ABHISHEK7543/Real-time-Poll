# Live Poll - Realtime Voting App

A real-time voting and polling application where users can create polls and vote in real time.

## Features

* Create polls
* Real-time voting
* Live vote updates
* Multiple voting options
* User-friendly interface
* Real-time communication

## Technologies Used

### Frontend

* React.js
* HTML
* CSS
* JavaScript

### Backend

* Node.js
* Express.js
* Socket.IO

### Database

* MongoDB

## Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Go to the project folder

```bash
cd Live-Poll-Realtime-Voting-App-main
```

### 3. Install frontend dependencies

```bash
cd client
npm install
```

### 4. Start frontend

```bash
npm start
```

### 5. Install backend dependencies

Open another terminal:

```bash
cd server
npm install
```

### 6. Start backend

```bash
npm start
```

## Environment Variables

Create a `.env` file in the backend folder and add your required environment variables.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```
